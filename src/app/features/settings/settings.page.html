Яндекс Диск · ручной обмен

Общая закрытая папка с правом «Редактирование» для обоих родителей. Каждый входит в свой Яндекс ID. Передающий родитель синхронизирует первым, принимающий — после него. Отправляются события, удаления и активные таймеры, но не профиль малыша.

Разрешения Яндекса дают приложению чтение и запись всего Диска; приложение обращается только к выбранной папке. Пароль и Client Secret не нужны.

Supabase · автоматический обмен

Синхронизация необязательна: дневник работает без интернета. Выполните миграцию базы Supabase и включите анонимный вход. Укажите адрес проекта, публичный анонимный ключ и одинаковый случайный UUID v4 семьи на обоих устройствах. Не используйте ключ с правами администратора. Идентификатор семьи — секрет приглашения: передавайте его только доверенному человеку.
